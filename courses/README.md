# Courses

课程是 AI Engineering Lab 的主要学习单元。

## Course Model

每个课程必须包含：

```
Course
 |
 ├── Objective
 ├── Source Basis
 ├── Lessons
 ├── Exercises
 ├── Experiments
 ├── Project Mapping
 └── Review
```

## Completion Criteria

课程完成不是阅读 README，而需要：

- 固定来源版本；
- 明确学习问题；
- 分章节记录；
- 保存证据范围；
- 有练习或实验；
- 映射真实项目；
- 记录未验证项。
