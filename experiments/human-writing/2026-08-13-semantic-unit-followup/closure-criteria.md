# Frozen closure criteria

- R01: exactly two bullets: official priority stays with the independent-validation boundary; primary source stays with the role of alternatives.
- R02: exactly one bullet containing capability, non-automatic limit, and caller responsibility; protected words preserved.
- R03: exactly one bullet containing cache benefit, freshness limit, and caller responsibility; protected words preserved.
- R04: exactly three bullets: pool permission + stopping condition + mandated transition together; before-course and after-course actions separate; all facts preserved.
- R05: exactly four numbered items on separate lines, in order; all facts preserved.
- R06: exactly two bullets: default choice + role of alternatives together; production-evidence boundary separate; all facts preserved.

Markdown backticks in the Protected declarations identify literal word spans; output need only preserve the words, not add backtick formatting. A case passes only when its structure and all facts, relations, modality, actors, protected words, and explicit format constraints are preserved.
