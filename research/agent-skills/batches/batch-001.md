# Agent Skills Research Batch 001

## Goal

Analyze at least 10 qualified GitHub AI Skills / Agent Skills repositories per batch when available.

## Quality Gate

A repository is not complete from stars or README metadata alone.

Required evidence:

- repository identity
- collected star count
- README analysis
- directory structure analysis
- SKILL.md or equivalent skill definition analysis
- scripts/references/evals analysis when available
- reusable pattern extraction
- comparison with idaibin/skills

## Per Skill Report

Each discovered skill should have an independent report containing:

- skill name
- purpose
- input/output expectations
- resources
- execution workflow
- validation approach
- reusable engineering patterns
- limitations
