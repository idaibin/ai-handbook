# Media Production System Map

> Historical architecture baseline and research references. Current workstream scope follows the [Handbook entrypoint](../README.md); this map does not resume Story Studio or turn recorded roles into a currently assigned owner.

- Stable route id: `media-production-system`
- Status: architecture/experiment only; repository and runtime not verified
- Product: Story Studio
- Lifecycle: `IP → Character → Script → Storyboard → Media Asset → Distribution`

## Outcome

Turn an IP or story basis into coherent reviewed visual and audio media.

```text
IP → Character → Script → Storyboard → Media Asset → Distribution
(Idea → World/Character Basis → Episode Plan → Script → Storyboard → Visual Generation → Motion/Edit → Audio → Subtitle → Review → Publish)
```

## Owned artifacts

- IP, world, character, rule and timeline bibles;
- episode plan, 60-second script, shot list and storyboard;
- character and scene references;
- image sequences, comics, animation and video;
- voice, music, effects, audio and subtitles;
- media source/master/rendition metadata, distribution and production evidence.

## Boundary

Story Studio is independent and currently architecture/experiment only. It consumes
shared Knowledge, Writing, Visual, Workflow and Evaluation capabilities, as well as
experimental Voice/Audio contracts.

Story Studio owns product-specific IP continuity, character/scene references and media
masters. Creatorway (formerly Createway) owns text and lightweight text+visual authored publishing content;
Forgeway owns software delivery. Story Studio runtime/code work is a separate Product
Delivery Task.

Do not claim a repository, production runtime or completed pilot exists.

## Validation gates

The proposed first experiment is one 60-second AI comic/drama unit with a complete
production manifest, task plan, prompt templates, cost record, continuity review,
text/subtitle accuracy check, audio/video probe, playback and publication readback.

The experiment is a plan and validation contract only. No part of that experiment has
been executed or verified by this architecture baseline.
