# AI Engineering Lab Domain Roadmap

## Purpose

建立个人 AI Engineering System：

信息发现 → 体系学习 → 知识沉淀 → 实践验证 → 工具能力 → 工程应用 → 持续优化。

目标不是收集链接，而是形成可验证、可复用的方法。

## Domain Priority

| Priority | Domain | Goal |
| --- | --- | --- |
| P0 | AI Engineering | Agent、Skills、Workflow、Evaluation、Knowledge Engineering |
| P1 | Software Engineering | Rust、Java、Frontend、Architecture、Testing |
| P2 | Creative & Media | AI Image、AI Video、Knowledge Visualization |
| P3 | Services & Applications | AI SaaS、Automation、Business Workflow |
| P4 | Business & Finance | Economics、Finance、Company Analysis |

## Learning Principle

公司不是学习分类，领域才是学习分类。

OpenAI、Anthropic、Google 等作为权威来源组织，不作为一级领域。

学习链路：

```
Domain
  ↓
Question
  ↓
Source
  ↓
Course
  ↓
Experiment
  ↓
Artifact
  ↓
Skill / Project Application
```

## Current Focus
