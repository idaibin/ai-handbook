# AI Engineering Lab v0.2 Minimal Workflow

> 历史门禁：下文保留 v0.2 当时的单一 MVP 与冻结规则，不作为当前三条长期主线的总入口。2026-10-27 的 Handbook、Forgeway、Craftway 定位见[根 README](../../README.md)。本澄清不恢复任何暂停项目或授权旧 next_action。

- **Version:** `0.2`
- **Status:** `FROZEN_PENDING_MVP_SELECTION`
- **Canonical owner:** `idaibin/ai-handbook`

## 门禁

没有经用户明确批准的单一 `MVP_BRIEF`，不得执行任何项目 Task。

`MVP_BRIEF` 必须回答：

- 谁在什么场景下遇到什么问题？
- 最小可直接使用的结果是什么？
- 如何在最多 7 天内运行并观察？
- 哪一个指标决定有效？
- 何时停止？

## 执行

一次只允许一个 MVP：

`Problem → Smallest Result → Run → Evidence → Keep / Change / Stop`

每轮最多留下四项：`MVP_BRIEF`、产物、运行证据、决策。失败优先缩小或停止，不扩建系统。

## 禁止

- 继续旧 Task 或历史 next_action；
- 新架构、平台、Registry、Workflow 或项目；
- 批量研究、批量资产、批量 Skill；
- 用代码量、文档量、资产数、测试数代替使用价值；
- 在没有真实运行证据时扩大范围。

## 解冻

只有用户明确批准一个 `MVP_BRIEF` 后，状态才可变为 `ACTIVE_MVP`。MVP 完成后必须回到 `FROZEN_DECISION`，先做 keep/change/stop 决策，再决定下一轮。
